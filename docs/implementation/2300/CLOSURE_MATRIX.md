## Axes and evidence fields

For each row, completion records the compiler/raw accepted predicate and
controlled destination; actual schema/storage/metadata adapter; independent
literal/reference content; route and positive-work witness; deterministic
forward/rejected/no-output interruption; pre-cutoff nonpublication versus
post-cutoff delivery; actual retry/consume/ACK/native owner; exact error and
denial metadata; and future-call event/resource baselines.

Partition aggregate rows by grouping, accepted function, operand/group/result
types and expression. Current parsed integer AVG is invalid: the frontend
requires FLOAT, so reproducing a new integer-average definition is not part of
this issue. Raw accepted STRING SUM and lexical MIN/MAX retain their current
semantics, including unresolved intern IDs; operand evaluation failure is
ERANGE, distinct from a FILTER's false row. Invalid schema/protected operation
and genuine strict-policy refusals require their own positive and negative
oracles rather than a blanket supported-domain refusal.

Partition selectors by full/delta/empty, ordinary/materialized/index/cache,
configured batching and legal pipeline/recursive/deletion composition. Name
representation adapters and both signed metadata and value assertions.
Worker-control, installed API and product qualification remain outside #2300;
that boundary cannot exclude a supported serial operator intersection.

Every financial certificate separately records Original WORK tariff identity,
performed lower, source-observation upper, assigned SOURCE promise identity,
and inherited correlated carry. A price, zero check, unused reservation,
FINISH or capacity is not a refund or a proof of the containing route. Local
Source bounds in `OPERATOR_SOURCE_ACCOUNTING.md` remain local until the full
actual caller/return and resource lifetimes are certified.
